📘 知识库问答系统 · 手动启动教程

写给零基础用户 · 跟着做就能把系统跑起来

🧩 先认识系统由 3 个"零件"组成

启动顺序必须是 ① → ② → ③,就像先开门、再开灯、最后进房间:

顺序零件是什么(大白话)怎么启动
①Docker + 数据库容器存放文档和索引的"货架",靠 Docker 这个"大箱子"装着先开 Docker Desktop,再双击脚本
②后端服务(大脑)负责检索、调 AI、组织回答的"管家"双击 start-backend.bat
③前端界面(门面)您在浏览器里看到的聊天页面双击 start-frontend.bat
1

启动 Docker Desktop(打开"大箱子")

💡 为什么:数据库(PostgreSQL + Qdrant)装在 Docker 里,Docker 不启动,后面一切白搭。
在桌面或开始菜单找到 Docker Desktop(图标是🐳一条载货的鲸鱼),双击打开。
然后等右下角/鲸鱼图标变成稳定的样子(首次约 30~60 秒,界面显示 "Engine running")。
⏳ 判断成功的标准:任务栏鲸鱼图标不再转圈,或 Docker 主界面左上角显示绿色的 "running"。
2

启动数据库容器(把"货架"摆好)

💡 为什么:光有 Docker 箱子还不行,得把 PostgreSQL(存文档信息)和 Qdrant(存语义索引)两个容器拉起来。
打开文件夹:本项目的 scripts 目录
找到 start-docker.bat,双击它。
会弹出黑色窗口,自动运行,最后显示两个容器 Started / Up:
kbqa-postgres Up ...
kbqa-qdrant Up ...
⏳ 这个窗口不要关(关了不影响,但建议留着)。看到 "Up" 字样即成功。若窗口一闪而过,说明出错了,截图给我看。
3

启动后端(把"管家"叫醒)

💡 为什么:管家负责接住您的问题、去货架找资料、再喊 AI 来回答。
还是在 scripts 文件夹里,找到 start-backend.bat,双击。
黑色窗口会滚动日志,最后出现类似:
Uvicorn running on http://127.0.0.1:8000
⏳ 这个窗口千万别关——关掉 = 管家下班 = 系统不能用。看到 "Uvicorn running" 即成功。
4

启动前端(打开"门面")

💡 为什么:前端就是您在浏览器里看到的聊天界面,它把后端的回答画出来。
找到 start-frontend.bat,双击。
黑色窗口出现:
Local: http://localhost:5173/
⏳ 这个窗口同样别关。看到 "Local" 即成功。
5

打开浏览器,开始使用 🎉

打开 Chrome / Edge,地址栏输入:
http://localhost:5173
回车 → 登录页 → 输入 管理员账号 admin / 你在 .env 里设置的密码 → 进入系统,就能问答了。
🛑 如何停止系统(和启动顺序相反)
停止原则:先关"门面",再关"管家",最后关"货架"。顺序反了可能导致数据损坏。
顺序操作大白话
1关闭前端黑窗口(start-frontend 那个)让门面歇业
2关闭后端黑窗口(start-backend 那个)让管家下班(窗口内按 Ctrl+C 更稳妥)
3双击 stop-docker.bat 或手动在 Docker Desktop 里停止容器收起货架(可选,嫌麻烦可一直开着)
4退出 Docker Desktop(右键托盘鲸鱼图标 → Quit)关掉大箱子
💡 省事提示:日常用完只需关第 1、2 步的窗口(前后端),Docker 留着不关,下次直接双击两个 bat 就恢复,几秒钟的事。
❓ 常见问题自查
现象原因 & 处理
双击 bat 一闪而过/报错多半是没按顺序——先确认 Docker Desktop 已开、容器已 Up
浏览器打不开 5173看第 4 步窗口是否还开着;关了窗口 = 服务停了
登录报"无法连接服务器"第 2、3 步的窗口还在吗?都在且显示 Up/running 就刷新页面
端口被占用(8000/5173 已在使用)可能有旧实例没关干净,重启电脑最省事
Docker 图标一直是黄的/转圈Docker 还在启动,多等一会儿;超 2 分钟就重启 Docker Desktop

有一步卡住了?把黑色窗口内容截图发给 AI 助手即可。
