# 财务指标口径详解与计算方法

> **本文档为示例资料，用于演示知识库问答。内容为通用财务知识整理。**

## 〇、估值指标

### 0.1 市盈率（PE，Price-to-Earnings Ratio）

```
市盈率 = 股价 / 每股收益（EPS）
等价写法 = 总市值 / 净利润
```

**含义**：投资者为每一元盈利愿意付多少钱。

**两种口径**：

| 类型 | 算法 | 说明 |
|---|---|---|
| 静态 PE | 股价 / 上一年度每股收益 | 用已确认的历史数据 |
| 动态 PE | 股价 / 预测每股收益 | 依赖预测，不确定性大 |
| TTM PE | 股价 / 最近四个季度每股收益 | 最常用 |

**怎么用**：
- PE 越高，说明市场对未来增长预期越高，或当前被高估
- **不同行业 PE 差异很大**，跨行业直接比较没有意义
  （银行通常 5~10 倍，科技股可能 30~50 倍）
- PE 为负说明公司亏损，此时该指标失效

### 0.2 市净率（PB，Price-to-Book Ratio）

```
市净率 = 股价 / 每股净资产
等价写法 = 总市值 / 净资产
```

**含义**：投资者为每一元净资产付多少钱。

**适用场景**：
- 重资产行业（银行、地产、钢铁）估值常用 PB
- 轻资产行业（软件、互联网）净资产意义不大，PB 参考价值低
- PB < 1 通常意味着"市值低于账面净资产"，可能是低估也可能是资产质量有问题

### 0.3 市盈率与市净率的区别

| 维度 | 市盈率 PE | 市净率 PB |
|---|---|---|
| 分母 | 每股收益（利润） | 每股净资产（家底） |
| 反映 | 盈利能力定价 | 资产价值定价 |
| 适用 | 盈利稳定的公司 | 重资产 / 周期行业 |
| 失效场景 | 公司亏损时 | 轻资产公司 |

**关键区别**：PE 看"赚多少钱"，PB 看"有多少家底"。
银行股常看 PB（因为利润波动大、资产是核心），
消费股常看 PE（因为盈利稳定）。

## 一、盈利能力指标

### 1.1 毛利率（Gross Margin）

```
毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
```

**含义**：每 100 元收入里，扣除直接成本后剩多少。

**注意区分**：
- **毛利** = 营业收入 - 营业成本（不含期间费用）
- **净利** = 毛利 - 期间费用 - 税费等

**行业参考**：

| 行业 | 典型毛利率 |
|---|---|
| 软件/SaaS | 60%~80% |
| 白酒 | 70%~90% |
| 消费电子 | 15%~30% |
| 制造业 | 15%~35% |
| 零售/贸易 | 5%~15% |
| 建筑工程 | 8%~15% |

### 1.2 净利率（Net Margin）

```
净利率 = 净利润 / 营业收入 × 100%
```

**含义**：每 100 元收入最终留下多少利润。

**跨行业比较无效**：
银行净利率通常 30%~40%，制造业 10%~15%。
但这不代表银行更赚钱 —— 差异来自杠杆，不是效率。

**跨行业应该用 ROE 或 ROA。**

### 1.3 净资产收益率（ROE）

```
ROE = 净利润 / 平均净资产 × 100%
平均净资产 = (期初净资产 + 期末净资产) / 2
```

**含义**：股东每投入 100 元，一年能赚回多少。

**杜邦分解**：

```
ROE = 净利率 × 总资产周转率 × 权益乘数

其中：
  净利率     = 净利润 / 营业收入
  总资产周转率 = 营业收入 / 平均总资产
  权益乘数   = 平均总资产 / 平均净资产（= 1 / (1 - 资产负债率)）
```

**三个杠杆方向**：

| 高 ROE 来源 | 代表行业 | 风险 |
|---|---|---|
| 高净利率 | 白酒、专利药 | 低 |
| 高周转率 | 零售、快消 | 中 |
| **高杠杆** | **银行、地产** | **高** |

> 同样是 20% 的 ROE，来自高净利率的和来自高杠杆的，
> 风险完全不同。看 ROE 必须拆开看来源。

### 1.4 总资产收益率（ROA）

```
ROA = 净利润 / 平均总资产 × 100%
```

**含义**：公司用全部资产赚钱的效率。不受杠杆影响，适合跨行业比较。

## 二、偿债能力指标

### 2.1 资产负债率

```
资产负债率 = 总负债 / 总资产 × 100%
```

**行业参考区间**：

| 行业 | 正常区间 | 说明 |
|---|---|---|
| 银行 | 90%~95% | 存款是负债，属正常经营模式 |
| 保险 | 85%~92% | 保单准备金是负债 |
| 房地产 | 70%~85% | 高杠杆行业 |
| 制造业 | 40%~60% | 常规区间 |
| 能源/公用事业 | 50%~65% | 重资产，需大量融资 |
| 软件/互联网 | 20%~40% | 轻资产 |
| 消费零售 | 40%~60% | 视租赁模式而定 |

> **关键**：不能拿制造业 50% 的标准去要求银行，
> 也不能拿银行 92% 的标准去评判制造业。

### 2.2 流动比率与速动比率

```
流动比率 = 流动资产 / 流动负债
速动比率 = (流动资产 - 存货) / 流动负债
```

**参考**：流动比率 1.5~2.0 较健康；速动比率 > 1.0 较健康。

**注意**：这两个指标对银行、保险不适用（它们的资产负债结构完全不同）。

### 2.3 利息保障倍数

```
利息保障倍数 = 息税前利润（EBIT） / 利息费用
```

**参考**：> 3 倍较安全；< 1.5 倍需警惕。

## 三、营运能力指标

### 3.1 存货周转率

```
存货周转率 = 营业成本 / 平均存货
存货周转天数 = 365 / 存货周转率
```

**含义**：存货一年周转几次。天数越短，周转越快。

**行业差异**：
- 生鲜零售：几天到十几天
- 制造业：30~90 天
- 白酒：300~900 天（越陈越值钱，不能简单说慢就不好）

### 3.2 应收账款周转率

```
应收账款周转率 = 营业收入 / 平均应收账款
应收账款周转天数 = 365 / 应收账款周转率
```

**含义**：货款平均多久收回。天数越长，占用资金越多。

### 3.3 总资产周转率

```
总资产周转率 = 营业收入 / 平均总资产
```

**含义**：每一元资产产生多少收入。轻资产公司通常更高。

## 四、成长性指标

### 4.1 同比增长率（YoY）

```
同比增长率 = (本期 - 上年同期) / 上年同期 × 100%
```

**注意**：必须用**同一期间**比较。Q3 同比要看去年 Q3，不是去年全年。

### 4.2 环比增长率（QoQ）

```
环比增长率 = (本期 - 上期) / 上期 × 100%
```

**注意**：环比受季节性影响大。
例如零售企业 Q4 环比必然高于 Q3（年末旺季），
这种增长不代表经营改善。

**判断方法**：看环比的同时看同比；同比为正说明真实增长。

### 4.3 复合增长率（CAGR）

```
CAGR = (期末值 / 期初值) ^ (1 / 年数) - 1
```

**含义**：多年平均年化增速。

**举例**：某公司 2020 年营收 50 亿，2025 年 83.1 亿，5 年 CAGR：
```
(83.1 / 50) ^ (1/5) - 1 = 10.7%
```

## 五、银行专项指标

### 5.1 净息差（NIM）

```
净息差 = 利息净收入 / 平均生息资产 × 100%
```

**含义**：生息资产的平均收益率减去计息负债的平均成本率。

**参考**：国内银行通常 1.8%~2.5%，低于 1.8% 说明息差压力大。

### 5.2 不良贷款率

```
不良贷款率 = 不良贷款余额 / 贷款总额 × 100%
```

**参考**：< 1.5% 较健康；> 2% 需关注。

### 5.3 拨备覆盖率

```
拨备覆盖率 = 贷款损失准备 / 不良贷款余额 × 100%
```

**含义**：为每 1 元不良贷款准备了多少"缓冲垫"。

**监管要求**：一般不低于 150%。高于 200% 说明抗风险能力较强。

### 5.4 资本充足率

| 指标 | 监管最低 | 说明 |
|---|---|---|
| 核心一级资本充足率 | 5%（+储备资本后约 7.5%） | 最严格 |
| 一级资本充足率 | 6%（+储备后约 8.5%） | |
| 资本充足率 | 8%（+储备后约 10.5%） | |

## 六、常见误区

### 误区 1：把累计数当单季数

```
错误：用「前三季度 60 亿」和「上半年 38.6 亿」相减算 Q3，
      得到 21.4 亿 —— 这个算法对，但要确认两个数都是累计口径。

正确：直接用单季度数据表，避免推算错误。
```

### 误区 2：跨行业比净利率

银行 36.9% vs 制造 12.6%，不能得出"银行更赚钱"的结论。

### 误区 3：只看 ROE 不看来源

同样是 20% ROE，高杠杆来的风险更大。

### 误区 4：环比增长当真实增长

Q4 环比 +8% 可能只是季节性，看同比才准。

### 误区 5：用静态数据判断动态变化

单季度数据波动很正常，要看趋势（至少 4 个季度）。
